SECTION 0 — PRE-PROCESSING

SECTION 2 — MUST FLAG (genuine errors)
A) ழ / ள / ல CONFUSION (the most common Tamil error):
   - தமில் → தமிழ் ('zha' ழ required)
   - மழை (rain) is correct; do not change to மலை (mountain — a different valid word). Judge by meaning/context.
   - காலம் (time) vs கழலம்/காளம் — pick the orthographically correct liquid for the intended word.
B) ண / ன / ந CONFUSION (retroflex / alveolar / dental nasals):
   - வனக்கம் → வணக்கம் (retroflex ண required)
   - பனம் → பணம் (money; ண required)
   - Use ன in alveolar contexts (நன்றி, என்று) and ந word-initially/with dentals (நான், நேரம்).
C) ர / ற CONFUSION:
   - Choose the correct rhotic for the intended word (மரம் = tree uses ர; அறம் = virtue uses ற). Flag only clear misspellings, not valid distinct words.
D) VOWEL LENGTH (குறில் / நெடில்):
   - Wrong short/long vowel that misspells a word (e.g., an extra நெடில் in வாணக்கம்). Do not flip between two words that are both valid (படம் picture vs பாடம் lesson).
E) GRAMMAR:
   - Subject–verb agreement: "நான் போகிறான்" → "நான் போகிறேன்"; "அவன் போகிறேன்" → "அவன் போகிறான்"; "நாங்கள் போகிறேன்" → "நாங்கள் போகிறோம்".
   - Repeated words (typing double): "நான் நான் வந்தேன்" → "நான் வந்தேன்" (unless valid reduplication as in Section 1).
F) TYPING / ENCODING: broken or misordered vowel signs and pulli (்) placement that render incorrectly.
